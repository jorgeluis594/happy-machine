¿Qué es un flujo de agentes?

Es la receta durable que decide qué trabajo ejecutar, cuándo avanzar y qué hacer con cada resultado.

1. Secuencia

El siguiente agente recibe datos del paso anterior.

Investigar→ Redactar→ Revisar

2. Decisión

El resultado o una regla determina la transición.

Evaluar→ ¿OK?→ SíPublicar NoCorregir

3. Paralelo y unión

Varias llamadas a Orca se lanzan juntas y luego se agregan.

Dividir⇉ Agente A Agente B Agente C ⇒Integrar

4. Espera durable

El proceso termina; el estado queda guardado hasta recibir un evento.

Propuesta→ Esperar
aprobación→ Continuar

5. Bucle controlado

Un trabajo se repite hasta cumplir una condición o agotar intentos.

Crear→ Validar↩ corregir
máx. 3 Aceptar

6. Subflujo reutilizable

Encapsula una receta completa detrás de entradas y salidas estables.

Entrada→ Revisión
editorial→ Resultado
flow: producir_informe steps: - agent: investigar - parallel: - agent: analizar_riesgos - agent: buscar_fuentes - wait: aprobacion - agent: redactar
COMPILA A →
Máquina de estados interna
  1. Cada paso tiene estado e intentos persistidos.
  2. El motor agenda las llamadas a Orca que estén listas.
  3. Solo avanza cuando sus condiciones quedan confirmadas.
  4. Tras un reinicio, reconstruye el trabajo pendiente.
Modelo híbrido: el autor escribe conceptos de workflow fáciles de entender; el compilador los transforma en estados y transiciones precisas para asegurar durabilidad.
