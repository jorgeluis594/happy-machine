Cómo un estado determina la siguiente ruta

El estado emite un outcome; la configuración lo traduce a una transición; el motor agenda el destino.

1. Estado evaluar
Orca ejecuta la operación
→
2. Resultado
outcome: needs_revision
+ data + artefactos
→
3. Motor
persiste y busca una transición compatible
evaluar
approved → transición hacia adelante
needs_revision → transición hacia atrás
blocked → estado de espera
publicar
redactar otra vez
esperar humano
# Definición del estado
states:
  evaluar:
    operation:
      agent: reviewer
    outputs:
      outcomes:
        - approved
        - needs_revision
        - blocked
# Rutas permitidas
transitions:
  - from: evaluar
    on: approved
    to: publicar
  - from: evaluar
    on: needs_revision
    to: redactar
  - from: evaluar
    on: blocked
    to: esperar_aprobacion
Una coincidenciaEl motor elige exactamente una transición normal.
Ninguna coincidenciaLa ejecución se detiene con un error de transición no contemplada.
Varias coincidenciasLa definición es ambigua y debe rechazarse o aplicar prioridad explícita.
